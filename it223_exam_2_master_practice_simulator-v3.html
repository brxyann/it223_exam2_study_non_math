⚡ IT 223 Exam 2 Comprehensive Quick Reference Cheat Sheet

1. Cryptography Fundamentals

• Symmetric: Same key for encryption/decryption; fast (e.g., AES, DES). Challenge: Secure key exchange.

• Asymmetric: Public/Private key pair; slow (e.g., RSA, ECC). Challenge: Key authentication (PKI).

• Hybrid System: Asymmetric for secure session key exchange; Symmetric for bulk data (e.g., TLS/HTTPS).

2. Hashing, MACs & Signatures

• Hash: One-way function, fixed output, integrity only.

• MAC / HMAC: Message + Shared Key → Integrity & Origin Authentication (No non-repudiation).

• Digital Signature: Hash encrypted with Sender's Private Key → Integrity, Authentication, & Non-Repudiation.

3. Access Control & Physical Security

• AAA: Authentication (Supplicant vs Verifier), Authorization (Least privilege), Auditing (Logs).

• 4 Ds of Physical Security: Deterrence → Denial → Detection → Delay.

• Power & Environment: UPS required; Temp 60–75°F, Humidity 40–60% (prevent static damage).

4. Networking & Firewalls

• Addressing: Switch = MAC (Layer 2); Router = IP (Layer 3); Port = Service; Socket = IP + Port.

• Firewall Types: Stateless (static IP/port header filter), Stateful (tracks TCP 3-way handshake state), Deep Packet Inspection (inspects payload).
